# RISS – Der Abstieg

Ein textbasiertes Dungeon-Roguelike. Steig in den Riss hinab, werde stärker, komm zurück – oder auch nicht.

**Spielen:** https://soupforbreakfast.github.io/Riss---Der-Abstieg/

Auf dem Handy über „Zum Startbildschirm hinzufügen“ als App installieren. Danach läuft das Spiel auch offline.
